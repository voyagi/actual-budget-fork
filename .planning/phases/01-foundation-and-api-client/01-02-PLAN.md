  <name>Task 1: Register Enable Banking sandbox application and download RSA key</name>
  <files>
    secrets/eb_private.pem

  <action>
    This step cannot be automated. Enable Banking generates the RSA key pair in the browser during application creation. The user must complete these steps manually.

    **Register at Enable Banking Control Panel:**

    1. Go to [enablebanking.com/cp](https://enablebanking.com/cp/applications)
    2. Create an account if you don't have one (email verification required)
    3. Click "New Application" (or equivalent)
    4. Choose **Sandbox** environment
    5. Fill in the application details (name can be anything, e.g. "actual-budget-fork")
    6. The browser will generate an RSA key pair and automatically download the private key as `<app-id>-private.pem`
    7. **Copy the Application ID** shown in the dashboard (you'll need this for `.env`)

    **Place the key and configure the environment:**

    8. Copy the downloaded `.pem` file to `secrets/eb_private.pem` in the repo root:
       ```
       cp ~/Downloads/<app-id>-private.pem secrets/eb_private.pem
       ```
    9. Copy `.env.example` to `.env`:
       ```
       cp .env.example .env
       ```
    10. Edit `.env` and replace `your-application-id-here` with your actual Application ID from step 7

    **Verify the setup:**

    11. Confirm `secrets/eb_private.pem` exists and starts with `-----BEGIN PRIVATE KEY-----` or `-----BEGIN RSA PRIVATE KEY-----`
    12. Confirm `.env` has a real value for `ENABLE_BANKING_APP_ID` (not the placeholder)

    **Important notes:**
    - The sandbox uses the same API URL as production (`https://api.enablebanking.com`). There is no separate sandbox URL.
    - The "Mock ASPSP" is the sandbox bank you'll use for testing in Phase 2.
    - This sandbox key is NOT your production key. Production requires a separate registration later (Phase 5).

    **Resume signal:** Type "done" with your Application ID (or just confirm the .env and key are in place). Do NOT paste the private key contents.

  </action>

  </verify>
