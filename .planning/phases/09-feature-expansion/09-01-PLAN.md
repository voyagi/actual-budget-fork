       **TOTP Secret Generation:**
       ```typescript
       import { TOTP, Secret } from 'otpauth';
       ```
       - `generateTotpSecret(issuer: string, label: string)` creates a `new TOTP({ issuer, label, algorithm: 'SHA1', digits: 6, period: 30 })` and returns `{ secret: totp.secret.base32, uri: totp.toString() }`.

       **TOTP Code Verification:**
       - `verifyTotpCode(secretBase32: string, code: string, lastUsedAt: number | null)` creates a TOTP from the secret, calls `totp.validate({ token: code, window: 1 })`. If delta is null, return `{ valid: false, usedAt: lastUsedAt ?? 0 }`. Compute `periodTs = Math.floor(Date.now() / 1000 / 30) + delta`. If `periodTs === lastUsedAt`, return invalid (replay). Otherwise return `{ valid: true, usedAt: periodTs }`.

       **Recovery Code Generation:**
       - `generateRecoveryCodes()` generates 8 codes using `crypto.randomBytes(6).toString('hex').toUpperCase()` per code, formatted as `XXXX-XXXX-XXXX`. Returns `{ codes: string[], hashes: string[] }` where hashes are `bcrypt.hashSync(code, 10)`.

       **Recovery Code Verification:**
       - `verifyRecoveryCode(submitted: string, hashedCodes: string[])` iterates hashes, uses `bcrypt.compareSync(submitted.replace(/-/g, ''), hash)`. On match, returns `{ valid: true, remaining: hashedCodes.filter((_, i) => i !== matchIndex) }`. No match: `{ valid: false, remaining: hashedCodes }`.
       - Note: strip dashes from submitted code before comparing since the hash was generated from the hex string before dash formatting. Actually, hash the formatted code (with dashes) and compare against the formatted submission. Keep it consistent: hash the `XXXX-XXXX-XXXX` formatted code, compare against the formatted submission.

       **TOTP Secret Encryption:**
       - `encryptTotpSecret(secret: string)` uses AES-256-GCM with key derived from `process.env.ACTUAL_SERVER_ENCRYPTION_KEY ?? process.env.SECRET_KEY ?? 'actual-totp-default-key'` + fixed salt `'totp-secret-encryption'` via `crypto.pbkdf2Sync(key, salt, 100000, 32, 'sha256')`. Generate random IV (12 bytes), encrypt, return `JSON.stringify({ iv: iv.toString('base64'), authTag: authTag.toString('base64'), ciphertext: ciphertext.toString('base64') })`.
       - `decryptTotpSecret(encrypted: string)` reverses the process.

       **Database Operations (uses getAccountDb()):**
       - `enrollTotp(userId: string, secretBase32: string, recoveryCodeHashes: string[])` encrypts the secret, inserts into `totp` table: `INSERT INTO totp (user_id, secret_enc, recovery_codes) VALUES (?, ?, ?)` with `secret_enc = encryptTotpSecret(secretBase32)`, `recovery_codes = JSON.stringify(recoveryCodeHashes)`.
       - `isTotpEnrolled()` queries `SELECT count(*) as cnt FROM totp` and returns `cnt > 0`.
       - `disableTotp()` runs `DELETE FROM totp`.
       - `getTotpStatus()` queries `SELECT recovery_codes FROM totp LIMIT 1`. Returns `{ enrolled: false, recoveryCodesRemaining: 0 }` if no row. Otherwise parses recovery_codes JSON and returns `{ enrolled: true, recoveryCodesRemaining: parsed.length }`.
       - `getStoredTotpSecret()` queries `SELECT secret_enc, last_used_at FROM totp LIMIT 1`, decrypts secret_enc, returns `{ secret: decrypted, lastUsedAt: row.last_used_at }`.
       - `updateTotpLastUsed(usedAt: number)` runs `UPDATE totp SET last_used_at = ?`.
       - `consumeRecoveryCode(remaining: string[])` runs `UPDATE totp SET recovery_codes = ?` with `JSON.stringify(remaining)`.
