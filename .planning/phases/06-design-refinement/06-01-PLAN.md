  <action>
Add two new exported hooks to `useEnableBankingStatus.ts`:

**1. `useConsentExpiryNotifications()` hook:**

Move the `isDismissed()`, `dismiss()`, and `formatExpiryDate()` helper functions from `ConsentExpiryBanner.tsx` into the top of `useEnableBankingStatus.ts` as module-level functions (not exported, just used internally by the hook).

The hook:
- Calls `useConsentExpiry()` to get sessions
- Uses `useDispatch()` from `@desktop-client/redux`
- Has a `useEffect` that runs when `sessions` changes:
  - First, runs the localStorage cleanup (two-pass stale key deletion from ConsentExpiryBanner's useEffect): collect keys starting with `consent-dismissed-` that do NOT end with today's `new Date().toDateString()`, then delete them in a second pass
  - Then, for each session where `isDismissed(session.sessionId)` is false:
    - If sessions.length === 1 (single session):
      - Dispatch `addNotification` with:
        - `id: \`consent-expiry-${session.sessionId}\``
        - `type: 'warning'`
        - `sticky: true`
        - `title: 'Bank connection expiring'` (or `'Bank connection expired'` when `session.urgency === 'expired'`)
        - `message:` For expired: `'${bankName} bank connection expired - re-authorize to resume automatic sync'`. For non-expired: `'${bankName} bank connection expires ${formatExpiryDate(session.validUntil)}'`. Where `bankName = session.aspspName ?? 'Bank'`.
        - `button: { title: 'Re-authorize', action: () => dispatch(pushModal({ modal: { name: 'enablebanking-external-msg', options: { sessionId: session.sessionId, aspspName: session.aspspName ?? undefined, aspspCountry: session.aspspCountry ?? undefined, reauth: true } } })) }`
        - `onClose: () => dismiss(session.sessionId)`
    - If sessions.length > 1 (multi-session):
      - Dispatch a single aggregated notification with:
        - `id: 'consent-expiry-multi'`
        - `type: 'warning'`
        - `sticky: true`
        - `title: 'Bank connections expiring'`
        - `message:` Count of sessions + context. E.g. `'${sessions.length} bank connections need re-authorization'`. If any are expired, append `' (${expiredCount} expired)'`.
        - `button: { title: 'Manage bank sync', action: () => navigate('/bank-sync') }` (use `useNavigate` from `@desktop-client/hooks/useNavigate`)
        - `onClose: () => { for (const s of sessions) dismiss(s.sessionId); }`
  - The `useEffect` dependency array: `[sessions.length, sessions.map(s => s.sessionId).join(',')]` to avoid re-running on referential changes when data is the same
- Returns void (fire-and-forget side-effect hook)

Import `addNotification` from `@desktop-client/notifications/notificationsSlice`, `pushModal` from `@desktop-client/modals/modalsSlice`, `useDispatch` from `@desktop-client/redux`, and `useNavigate` from `@desktop-client/hooks/useNavigate`.

**2. `useBankSyncNotification()` hook:**

- Uses `useSelector(state => state.account.accountsSyncing)` from `@desktop-client/redux`
- Uses `useDispatch()` from `@desktop-client/redux`
- Uses `useRef<boolean>(false)` to track whether a notification is currently active (prevents orphaning)
- Has a `useEffect` that runs when `accountsSyncing.length` changes:
  - If `accountsSyncing.length > 0`:
    - Dispatch `addNotification` with:
      - `id: 'bank-sync-in-progress'`
      - `type: 'message'`
      - `sticky: true`
      - `message: \`Syncing... ${accountsSyncing.length} accounts remaining\``
    - Set `wasActive.current = true`
  - Else if `wasActive.current === true` (sync just finished):
    - Dispatch `removeNotification({ id: 'bank-sync-in-progress' })`
    - Set `wasActive.current = false`
- Returns void

Import `useSelector` from `@desktop-client/redux`.

Both hooks are side-effect-only (no return value needed). They will be called from FinancesApp.tsx in Task 2.
