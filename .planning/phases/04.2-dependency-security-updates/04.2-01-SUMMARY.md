- **Found during:** Task 2 (HIGH severity CVE remediation verification)
- **Issue:** Plan assumed `yarn install --refresh-lockfile` would resolve lodash 4.17.21 to 4.17.23. But multiple packages (including upstream deps) declare `^4.17.15`, `^4.17.20`, `^4.17.21` ranges that are satisfied by 4.17.21, preventing the refresh from bumping them.
- **Fix:** Added `"lodash": ">=4.17.23"` to package.json resolutions in the same Task 2 commit
- **Files modified:** package.json, yarn.lock
- **Verification:** node check-yarn-versions2.js shows OK: lodash - no 4.17.21 entries remaining
- **Committed in:** `0f06607fc` (Task 2 commit)
