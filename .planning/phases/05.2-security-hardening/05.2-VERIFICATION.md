### 3. OpenID Redirect Blocking in Production

**Test:** With server_hostname set to a non-localhost URL (e.g. https://budget.example.com), attempt an OpenID flow that would redirect to localhost.
**Expected:** Redirect is blocked. Console shows warning log.
**Why human:** Requires OpenID provider configuration and server_hostname set to production value.

### 4. Regex Timeout / Catastrophic Backtracking

**Test:** Create a Handlebars rule with a regex-literal pattern known for catastrophic backtracking (e.g. `/(a+)+$/`) and apply it to a long string of 'a's.
**Expected:** Pattern is blocked by isRegexSafe pre-check (returns original value, logs warning).
**Why human:** The isRegexSafe pre-check covers nested quantifiers but not all possible ReDoS patterns. Novel patterns without nested quantifiers but with exponential backtracking (e.g. some alternation patterns) could still cause issues. The synchronous approach has no runtime timeout fallback.

### 5. PBKDF2 Re-encryption Migration

**Test:** Encrypt a file with the old code (10K iterations, no iterations field in metadata). Then open the file with the new code.
**Expected:** File opens successfully (backward compat), and after next keyTest, the test content on the server is updated with 100K-iteration metadata.
**Why human:** Requires server infrastructure and pre-existing encrypted file from before the change.
