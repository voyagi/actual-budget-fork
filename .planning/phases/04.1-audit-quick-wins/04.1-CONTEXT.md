<decisions>
## Implementation Decisions

### Security Headers & Restrictions
- CSP policy uses `style-src 'unsafe-inline'` to accommodate React's inline style objects. Script-src should be `'self'` only.
- Auth-specific rate limiting: 5 attempts per 15 minutes per IP on login, bootstrap, and OpenID endpoints. Separate from the global 500/min limit.
- CORS restricted via environment variable `ACTUAL_CORS_ORIGIN`. Defaults to `http://localhost:3001` in development. User sets their domain in production Docker config.
- HSTS max-age: 1 year (31536000 seconds). Safe because Caddy handles HTTPS certs automatically.
- Dockerfile: Add `USER node` before CMD (node:22-bookworm-slim already has a node user).
- Content-Type: Add explicit `Content-Type: application/json` to direct `res.send()` calls in app-sync.ts.

### Accessibility Additions
- aria-live regions: Add `aria-live="polite"` directly to individual components (BankSyncStatus, ConsentExpiryBanner, budget total containers). Each component owns its own announcement.
- Skip-navigation: "Skip to main content" link targets the main content/route area (past the sidebar). Standard skip-nav pattern.
- Banner urgency icon: Different icons per urgency level (info circle for "soon", warning triangle for "urgent", error octagon for "expired"). Not just color-only differentiation.
- focus-visible: Replace `outline: none` in DateSelect with a `:focus-visible` equivalent using the existing boxShadow pattern.

### Design System Fixes
- ConsentExpiryBanner dismiss button: Replace `&times;` character with `SvgDelete` icon component from the design system.
- AccountRow re-authorize button: Replace raw HTML `<button>` with `Button variant="bare"` from `@actual-app/components/button`. Inherits hover, focus-visible, active states.
- EnableBankingExternalMsgModal width: Replace `width: '30vw'` with `width: clamp(400px, 30vw, 600px)` for responsive bounds.
- localStorage cleanup: ConsentExpiryBanner self-cleans old dismiss keys on mount. Scan for keys older than today and delete them.

### Remaining Items (No Gray Areas)
- perf-1: Enable terser compression in vite.config.mts (remove `compress: false, mangle: false`).
- fq-5: Fix 2 FIXME error codes in app-sync.ts (404 for file not found, boolean conversion).
- dx-6: Delete 2 unused files (querySlidingWindow.ts, useTransactionFormulaExecution.ts).
- Spelling: Normalize "authorise"/"authorize" to American English across fork files.

### Scope Exclusion
- cfg-1 (token expiration default): DROPPED. 'never' is the correct default for a personal self-hosted app. Forced re-login adds friction with no security benefit for single-user deployment.

### Claude's Discretion
- Exact CSP directive values beyond style-src and script-src (img-src, font-src, connect-src, etc.)
- Rate limiting error response format (standard 429 vs custom JSON)
- HSTS includeSubDomains and preload flags
- Which specific SVG icons to use for each urgency level (choose from existing design system icons)
- Spelling normalization scope (fork files only vs all modified files)

</decisions>
