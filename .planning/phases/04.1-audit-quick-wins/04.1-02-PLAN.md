**B. Replace outline:none with focus-visible in DateSelect (a11y-5):**

In `packages/desktop-client/src/components/select/DateSelect.tsx`, the `calendarStyles` CSS-in-JS object (line 78) contains nested selectors processed by @emotion's `css()` function.

1. In the `'& td [role="button"]'` selector (line 128), REMOVE the line:
   ```
   outline: 'none',
   ```

2. Add a new `'& td [role="button"]:focus-visible'` nested selector AFTER the existing `'& td[data-focused] [role="button"]'` selector (line 152-155). Use the same boxShadow pattern already used for data-focused:
   ```typescript
   '& td [role="button"]:focus-visible': {
     boxShadow: `0 0 0 2px ${theme.calendarSelectedBackground}`,
   },
   ```

This ensures:
- Mouse users see no focus ring (browser default for mouse clicks is no :focus-visible)
- Keyboard users see the 2px boxShadow ring (matching the existing data-focused style)
- The existing `data-focused` selector still works for React Aria's keyboard navigation state

3. Also add `outline: 'none'` specifically to the non-focus-visible state to prevent browser default outline while keeping the focus-visible ring:
   ```typescript
   '& td [role="button"]:focus:not(:focus-visible)': {
     outline: 'none',
   },
   ```

   OR simply rely on the boxShadow for :focus-visible and let the browser default outline show for :focus without :focus-visible (this is the more accessible option - if in doubt, use the simpler approach of just removing `outline: 'none'` and adding the `:focus-visible` boxShadow selector).
