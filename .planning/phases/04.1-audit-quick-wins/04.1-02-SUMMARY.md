## Decisions Made

- aria-live="polite" chosen over "assertive" because sync status, consent banners, and budget totals are informational (not critical alerts). Polite mode waits for user to finish current interaction before announcing.
- urgencyIcons defined at module level (not inside component function) to avoid object recreation on every render. Shareable between SessionBanner and MultiSessionBanner.
- UrgencyIcon variable pattern (assign component to variable, conditional render) chosen over React.createElement approach for cleaner JSX and TypeScript type inference.
- :focus-visible with boxShadow chosen to match the existing data-focused style (same 2px ring) for visual consistency between React Aria keyboard state and native :focus-visible.
