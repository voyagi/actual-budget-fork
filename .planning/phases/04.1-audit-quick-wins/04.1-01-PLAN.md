Modify `packages/sync-server/src/app.ts` to add four security features. All changes go in the middleware section before route mounts.

**A. Restrict CORS origin (cfg-2):**
Replace `app.use(cors())` (line 30) with:
```typescript
app.use(cors({ origin: config.get('corsOrigin') }));
```
This reads from the convict field added in Task 1. The `config` import already exists in app.ts.

**B. Add HSTS header (sec-6):**
Inside the existing `if (process.env.NODE_ENV !== 'development')` block (line 32), before the existing `rateLimit`, add:
```typescript
app.use((_req, res, next) => {
  res.set('Strict-Transport-Security', 'max-age=31536000');
  next();
});
```
HSTS is gated on non-development to prevent browsers from refusing future HTTP connections during local dev.

**C. Add CSP header (sec-1):**
In the same `if (process.env.NODE_ENV !== 'development')` block, add after HSTS:
```typescript
app.use((_req, res, next) => {
  res.set(
    'Content-Security-Policy',
    [
      "default-src 'self'",
      "script-src 'self'",
      "style-src 'self' 'unsafe-inline'",
      "img-src 'self' data:",
      "font-src 'self'",
      "connect-src 'self'",
      "frame-ancestors 'none'",
    ].join('; '),
  );
  next();
});
```
`style-src 'unsafe-inline'` is required per user decision (React inline style objects). `connect-src 'self'` is correct because all Enable Banking API calls route through the sync-server backend, not directly from the browser.

Or combine HSTS and CSP into a single middleware function to reduce overhead:
```typescript
app.use((_req, res, next) => {
  res.set('Strict-Transport-Security', 'max-age=31536000');
  res.set(
    'Content-Security-Policy',
    "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'",
  );
  next();
});
```
