## Decisions Made

- SvgDelete from `@actual-app/components/icons/v0` (not v1) - v0 is the correct icon set for delete/close icons in the Actual design system. The plan's interface examples showed this pattern from Notifications.tsx.
- Two-pass localStorage cleanup: collect keys into an array first, then iterate the array to delete. The plan explicitly noted this is CRITICAL because deleting during `for (let i = 0; i < localStorage.length; i++)` iteration corrupts the index and causes keys to be skipped.
- `clamp(400px, 30vw, 600px)` bounds: minimum 400px ensures readability on small/narrow viewports, preferred 30vw scales proportionally, maximum 600px prevents the modal from spanning the full screen on very large monitors.
- `Button variant="bare" onPress={handleReauth}` replaces `<button onClick={handleReauth}>` - the design system Button component automatically provides `background: none`, `border: none`, `cursor: pointer` plus hover/focus-visible/active states. Manual inline styles for those properties were removed.
- British spelling replacement was scoped to user-facing string literals (4 occurrences in Trans blocks and t() calls). Code identifiers like `authorizeEnableBank` (already American English) were not touched.
