1. Open Chrome on desktop and navigate to `https://actual.local` (or whatever CADDY_HOST is set to in .env)

   - Run: `docker compose exec caddy cat /data/caddy/pki/authorities/local/root.crt > caddy-root.crt`

9. Verify: the budget and test transaction from Step 4 are still present

**Step 3 - Phone HTTPS via Cloudflare Tunnel (INFRA-02):**

<task type="checkpoint:human-verify" gate="blocking">

  <files></files>
  <action>
Human verifies production Enable Banking OAuth flow and real bank sync. Present the verification steps below to the user and wait for confirmation.

**Prerequisites (human action required before this step):**
- Register a production application at enablebanking.com/cp (environment: PRODUCTION)
- Set the redirect URL to `https://<your-tunnel-hostname>/enablebanking/callback`
- Upload the RSA public key (generate new pair if required, or reuse sandbox key)
- In the EB control panel, click "Link accounts" and authorize at least one real bank
- Confirm app status changes from "pending" to active (restricted mode)
- Update `.env`: set `ENABLE_BANKING_APP_ID` to the new production app ID
- If a new RSA key was generated, replace `secrets/eb_private.pem` with the production key
- Restart: `docker compose restart sync-server`

**Step 5 - Production OAuth (INFRA-01 partial):**
1. Open the app (via Cloudflare Tunnel URL on phone or Caddy URL on desktop)
2. Navigate to an account -> Link bank account (Enable Banking)
3. Complete the OAuth flow at your real bank's login page
4. Verify: you return to the app and bank accounts are listed for linking

**Step 6 - Real bank sync (INFRA-01 final):**
5. Link a bank account to an Actual account
6. Trigger a manual sync
7. Verify: real transactions from your bank appear in the Actual account
8. Wait for the next scheduled automatic sync (or check sync logs)
9. Verify: automatic sync completes and new transactions (if any) appear

**If Step 5 or 6 fails:**
- Check `docker compose logs sync-server` for Enable Banking API errors
- Common issues: redirect URL mismatch (must match Cloudflare Tunnel hostname exactly), app still in "pending" state (link own account first), RSA key mismatch
