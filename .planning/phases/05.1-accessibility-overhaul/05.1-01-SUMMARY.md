## Decisions Made

- `consent-urgency.ts` placed in `utils/` (not `components/` or `hooks/`) - it is domain logic shared across multiple concerns, not tied to a component or hook lifecycle
- `urgencyColors` and `urgencyIcons` exported as const module-level values (not factory functions) - they are pure data with no runtime dependencies beyond theme tokens
- `ConsentUrgency` type re-exported from hook (`useEnableBankingStatus.ts`) for backward compat so no existing consumers need changes
