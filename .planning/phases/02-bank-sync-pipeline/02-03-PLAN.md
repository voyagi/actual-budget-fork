       - Look up `eb_account_uid` and `actual_account_id` from `eb_account_map` WHERE `actual_account_id = accountId` OR `eb_account_uid = accountId`. Store the full row as `mapRow`.
       - Call `getTransactions(ebAccountUid, startDate)` to get `{ booked, pending }`
       - Normalize each transaction: `booked.map(t => normalizeTransaction(t, true))` and `pending.map(t => normalizeTransaction(t, false))`
       - Call `getBalances(ebAccountUid)` to get balance data
       - Call `extractBalance(balancesData.balances)` to get integer balance
       - **CRITICAL (actual_account_id resolution fix):** Log to `eb_sync_log` using the Actual UUID from the map row, NOT from req.body.accountId (which may be an EB UID during sync).     8. `POST /remove-session` - Remove a linked session:
       - Extract `{ sessionId }` from req.body
       - DELETE FROM `eb_account_map` WHERE `session_id = sessionId`
       - DELETE FROM `eb_sessions` WHERE `id = sessionId`
       - Return `{ status: 'ok' }`

    9. `POST /sync-status` - Get last sync status per account:

       - Return `{ status: 'ok', data: { statuses: { [accountId]: lastLogEntry } } }`
