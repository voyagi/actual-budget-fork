  <name>Task 1: Implement all Enable Banking routes in app-enablebanking.js</name>
  <files>packages/sync-server/src/app-enablebanking/app-enablebanking.js</files>
  <action>
    Rewrite `app-enablebanking.js` to add 8 routes. Keep existing `/test-auth` and `/status` routes. Import from service, utils, migrations, and errors modules. Call `runMigrations()` at module load time (top of file, after imports).

    **CRITICAL: Route placement rules:**
    - `GET /callback` and `GET /link` MUST be placed BEFORE `export { app as handlers }` (unauthenticated - browser redirect from bank has no Actual session)
    - All other new routes go AFTER `app.use(validateSessionMiddleware)` (session-authenticated)

    **Unauthenticated routes (before export):**

    1. `GET /test-auth` - EXISTING, keep as-is
    2. `GET /callback` - OAuth callback from bank redirect:
       - Extract `code` and `state` from query params
       - Validate `state` exists in `eb_sessions` table (CSRF protection) - reject 400 if not found
       - Call `exchangeCode(code)` to get `{ session_id, accounts, valid_until }`
       - Update `eb_sessions` row: set `id = session_id`, `accounts = JSON.stringify(accounts)`, `valid_until` WHERE `state = state`
       - For each account in accounts, INSERT OR IGNORE into `eb_account_map` with `session_id`
       - Redirect to `/enablebanking/link?state=` + state
    3. `GET /link` - Serve link.html (static file):
       - `res.sendFile(path.join(__dirname, 'link.html'))` or inline the HTML

    **Authenticated routes (after session middleware):**

    4. `POST /get-banks` - List available banks for a country:
       - Extract `{ country }` from req.body
       - Call `getAspsps(country)`
       - Return `{ status: 'ok', data: result }`

    5. `POST /create-auth` - Initiate OAuth:
       - Extract `{ aspspName, aspspCountry }` from req.body
       - Generate UUID as `state` (use `crypto.randomUUID()`)
       - INSERT pending row into `eb_sessions` with `state`, `aspsp_name`, `aspsp_country`
       - Call `createAuth({ aspspName, aspspCountry, redirectUrl: process.env.ENABLE_BANKING_REDIRECT_URL || 'http://localhost:5006/enablebanking/callback', state })`
       - Return `{ status: 'ok', data: { url: result.url, state } }`

    6. `POST /get-accounts` - Poll for session completion:
       - Extract `{ state }` from req.body
       - Query `eb_sessions` WHERE `state = state`
       - If `accounts` is populated (not null): parse JSON, return `{ status: 'ok', data: { accounts: parsedAccounts } }`
       - If not yet: return `{ status: 'ok', data: {} }`

    7. `POST /transactions` - Fetch and normalize transactions:
       - Extract `{ accountId, startDate }` from req.body
       - Look up `eb_account_uid` and `session_id` from `eb_account_map` WHERE `actual_account_id = accountId` OR `eb_account_uid = accountId`
       - Call `getTransactions(ebAccountUid, startDate)` to get `{ booked, pending }`
       - Normalize each transaction: `booked.map(t => normalizeTransaction(t, true))` and `pending.map(t => normalizeTransaction(t, false))`
       - Call `getBalances(ebAccountUid)` to get balance data
       - Call `extractBalance(balancesData.balances)` to get integer balance
       - Log to `eb_sync_log`: INSERT with account_id, eb_account_uid, status='success', transactions_added count
       - Return `{ status: 'ok', data: { transactions: { all: [...booked, ...pending] }, balances: extractedBalance, startingBalance: extractedBalance } }`
       - On error: log to `eb_sync_log` with status='error' and error_message, then re-throw

    8. `POST /remove-session` - Remove a linked session:
       - Extract `{ sessionId }` from req.body
       - DELETE FROM `eb_account_map` WHERE `session_id = sessionId`
       - DELETE FROM `eb_sessions` WHERE `id = sessionId`
       - Return `{ status: 'ok' }`

    9. `POST /sync-status` - Get last sync status per account:
       - Extract `{ accountIds }` from req.body (array)
       - For each accountId, query `eb_sync_log` WHERE `account_id = ?` ORDER BY `synced_at DESC LIMIT 1`
       - Return `{ status: 'ok', data: { statuses: { [accountId]: lastLogEntry } } }`

    Wrap all async route handlers with `handleError()` from `./util/handle-error.js`.

    Use `import { getAccountDb } from '../account-db.js'` for DB access. Use `db.all()` for SELECT queries, `db.first()` for single row, `db.mutate()` for INSERT/UPDATE/DELETE.
