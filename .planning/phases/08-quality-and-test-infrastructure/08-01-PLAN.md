  <action>
1. **Install @vitest/coverage-v8** as a dev dependency in sync-server:
   ```
   yarn workspace @actual-app/sync-server add -D @vitest/coverage-v8
   ```

2. **Update `packages/sync-server/vitest.config.ts`** to add v8 coverage config scoped to fork files:

```typescript
export default {
  test: {
    exclude: ['**/node_modules/**', '**/dist/**', '**/build/**'],
    globalSetup: ['./vitest.globalSetup.js'],
    globals: true,
    coverage: {
      enabled: false,
      provider: 'v8',
      include: [
        'src/app-enablebanking/**',
        'src/scheduler.ts',
        'src/util/alerter.ts',
        'src/util/metrics.ts',
        'src/util/audit.ts',
        'src/util/logger.ts',
      ],
      exclude: ['**/node_modules/**', '**/dist/**', '**/build/**'],
      thresholds: {
        lines: 60,
      },
      reporter: ['text', 'lcov'],
    },
    maxWorkers: 2,
  },
};
```

Key points:
- `enabled: false` keeps coverage OFF for normal `yarn test` runs (avoids slowing every run)
- `provider: 'v8'` uses V8 native instrumentation (no Babel needed)
- `include` lists ONLY fork-specific files (not upstream sync-server code)
- `thresholds.lines: 60` is the starting target (non-blocking initially since enabled: false)
- `reporter: ['text', 'lcov']` produces console output + lcov for CI integration
- To run with coverage: `yarn workspace @actual-app/sync-server test --coverage --coverage.enabled`

Do NOT add a CI workflow step for coverage yet (can be added later when threshold is consistently met). Do NOT modify the test script in package.json.
  </action>
